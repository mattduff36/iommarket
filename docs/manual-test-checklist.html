Manual test checklist

Everything that landed in adaptive listing photos and admin lifecycle / recoverability. Ticks are saved in this browser. Default view is P0 smoke.

Accounts you need

Admin, a private seller, and a second user for reports and reviews. A dealer account is needed for dealer listings, dealer reviews, and downgrade. Use throwaway listings — several checks take listings down or disable accounts.

Suggested order

  1. Seller photos on /sell/private: upload mixed shapes, reorder, set primary, save, then check home, search, and the listing page.
  2. Submit that listing and work /admin/listings: ALL default, instant status filter, PENDING at the top, approve / reject / take down / restore.
  3. As another user: report the live listing, favourite it, then confirm 404s and owner-visible reasons after take-down.
  4. Operations: /admin/reports, /admin/reviews, /admin/users, then payments, categories, pages, waitlist, and /admin/audit.

Known gaps

Playwright journeys for both workstreams were written but not run against a safe database. HEIC depends on Cloudinary. Ripple webhooks are unit-tested only.

Listing take-down / reject reasons: Fraud or scam, Prohibited item, Misleading or inaccurate, Duplicate listing, Policy violation, Safety concern, Other (notes required). Account disabled is system-only and should not appear in the admin dropdown.
