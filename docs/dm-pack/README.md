# Private DM policy pack generation

The generator builds a dated private working pack from the canonical policy Markdown and moderation taxonomy. Generated files belong under `private/`, which is gitignored. They are working materials and must not be described as legally approved.

Run:

```bash
npm run dm-pack -- --date=2026-08-17
```

This generates Markdown, JSON, a line redline, a change schedule, a moderation matrix, the Vehicle Check source register, DOCX and PDF review copies, and a ZIP containing the complete allowlisted pack under `private/dm-policy-pack-YYYY-MM-DD/`.

Binary files are generated by the repository's Node tooling, so Pandoc and a system PDF engine are not required. DOCX metadata and archive entry timestamps are pinned to the requested pack date, and the outer ZIP includes only the expected source files plus the current DOCX and PDF.

Use `--no-convert` to generate only the source artifacts, or `--output=<path>` to choose another private output directory.
